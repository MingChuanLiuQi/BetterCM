新增进程/窗口测试覆盖：缺参数 helper 静默非零退出、主实例退出等待及超时、根/子菜单工具窗口类型、呈现通知异常后的清理与再次呈现。40 秒假命令在无限等待策略下返回成功，期间可打开新菜单；原显式 30 秒超时故障夹具仍检查 IPC 断开后不终止用户任务。另以 6.5 秒完整树夹具确认增强模式独立读取预算。压力测试使用假命令，不拿真实用户文件模拟长任务。

## 窗口与实际交互

使用 computer-use 的 `@oai/sky` 操作正式发布程序的独立配置副本：后台启动后再次运行，首次打开设置；观察正常页及完整底部操作栏；把测试配置改为损坏内容后，恢复入口出现、保存禁用；真实点击“恢复上次备份”后错误区消失、保存恢复。磁盘核对恢复文件与备份完全一致，损坏内容另存副本。

缩窄窗口后操作栏仍完整，Tab 进入背景材质 ComboBox 时有可见蓝色焦点轮廓。没有保存到用户日常设置，也没有修改日常自启项。界面检查的配置仅用于独立数据目录，右键接管关闭，热键为 Ctrl+Alt+F24。

尺寸逻辑测试包含 1366×728 / 1920×1040 工作区及 100%、125%、150%、175%、200% 的代表性组合；WPF 组件实际按 960×520 DIP 工作区对应的 936×496 窗口布局，检查保存按钮落在窗口范围内。没有实际切换 Windows 显示设置，不将这些断言等同于多显示器混合 DPI 实测。

后台主进程在打开设置前的一次私有内存采样为 82,145,280 字节（约 78.3 MiB），不含辅助进程。这不是总常驻内存，也不能与审查报告中的工作集数值直接作百分比比较。
