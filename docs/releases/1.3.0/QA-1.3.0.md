## 新增检查和真实发现

- 实际资源管理器窗口中创建 A/B 两个测试标签，分别选择独立夹具 A-one.txt / B-only.txt。初版仅用 IsWindowVisible 时，第二标签确实错误返回第一个标签的 A-one；失败证据保留 tab-b-development-1.3.0.json。修正内部子窗口 Z 序检查后开发版通过，再以最终发布目录重复检查 A/B 精确捕获和绑定，两份报告各 2 项。
- 同目录双标签分别保留 A-one/A-two 的选区。最终发布程序在第二标签捕获并持有绑定，实际点击切到第一个标签，继续校验时旧绑定被拒绝；同目录测试 3 项通过。没有通过修改目录字符串来伪造换标签，也没有执行用户文件动作。独立测试 Explorer 窗口已关闭。
- 四项预览所有权逻辑检查：未创建菜单就取消恢复、旧取消不覆盖新预览、普通菜单替代预览、恢复最新保存值。测试使用可控的配置应用回调，不声称全面复现所有慢 Shell 扩展上的实际设置预览。
- UI 补全夹具挂起时，“原”先显示已加载原生查看，继续输入“原生打开”立即过滤为空且只查询一次；补全后显示带完整路径的真实叶子。旧搜索取消检查按当前已过滤的结果验证，不保留过期未过滤列表。
- 粘贴规范化覆盖中英访问键、全角括号与数字；原位替换保持原名称、助记键和快捷键，命令基址映射正确；没有占位则在最后属性区前插入，已有规范动词和嵌套同名项目不重复或覆盖。既有真实跨宿主复制/剪切粘贴继续通过。
- 图标和大小独立结果、慢项超时不丢另一项、取消不发布、50 次请求不积累探测均通过。只是有界等待和每类单项在飞，不能真正中止同步网络 I/O；没有用真实离线 SMB/WebDAV 验证所有网络栈行为。
- 日志达到容量边界轮转、20 个并发写入跨边界无丢条、超长单条限长通过；原有三个宿主并发日志检查继续通过。
