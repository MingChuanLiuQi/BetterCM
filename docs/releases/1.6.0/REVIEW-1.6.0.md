# BetterCM 1.6.0 设置体验调整

用户反馈自定义动作、系统项目两页拥挤粗糙，设置说明在多轮迭代后不够自然。本轮整理真实 WPF 设置界面，不新增右键功能，不更改菜单材质控制和 Shell 命令执行协议。

- 六页统一标题、简短说明和分区层次；“一级菜单”页改名“内置动作”，因为它只管理 BetterCM 内置动作，不涵盖所有一级项目。
- 三个设置表格使用局部样式，54 DIP 行高、44 DIP 表头、真实单元格内边距和垂直居中；勾选列水平对齐。全局 CheckBox 模板在无内容时仍留出文字区域，表格专用尺寸和 Stretch 单元格消除了偏移。样式仅由 MainWindow 合并，不影响右键菜单几何与其他应用窗口。
- 自定义动作、系统项目使用圆角卡片、就近工具栏、空状态、条目计数和目标名称；名称和来源分别显示，长内容悬停可读。无选中项时编辑、移除禁用。
- 经典模式明确解释禁用原因，提供“使用增强模式”入口；切换仅编辑当前设置，保存后生效，不清空原配置。预览、重置动画、撤销、关闭窗口均说明真实作用，技术参数保留在确有必要的自定义动作字段和诊断页。
- 自定义动作编辑框改为可调整大小的滚动表单，固定底部操作栏；“应用到列表”明确尚需设置页保存。保留全部原有字段、参数验证和执行语义。
- 系统项目每次进入页面或点击更新时读取最近一次右键结果，按稳定 Key 保留不同目标的未保存勾选，保存合并所有访问过的条目，撤销清空临时修改；标题和来源随新结果更新，不保留旧文案。
- 快捷键有效状态独立于提示文本，不再用提示语前缀控制保存按钮；还原后显式恢复保存状态，修复仅外观被外部更新且快捷键未变时保存仍禁用的问题。关闭动画时同时禁用展开选项。

修改前标签 backup-before-1.6.0 及旧安装包保留。没有删除历史输出，没有恢复开始／任务栏固定入口；快捷访问与 BetterCM 自身直接显示功能保留。最终验证见 QA-1.6.0.md。
