# BetterCM 2.0.0 — 2026-10-24

本轮实现功能性迭代：场景规则与菜单方案、一层自定义分组、批量重命名、收藏目录复制／移动。2026-10-24 完成本地候选，2026-10-25 发布。正式发行从主仓库干净提交重新验证与构建，版本标签、程序 Build 和发行清单对应同一提交；实际范围见 GitHub Release 的 Verification.zip，本地候选保留为开发历史。

## 场景规则与方案

先在设置中关闭经典模式，使用增强菜单。选择“内置动作 → 场景与分组”，或编辑自定义动作展开“场景规则与菜单分组”。可限定文件、文件夹、空白处、名称通配符、目录及选中数量。数量最大值 0 表示不限；空白处计为 0 项。名称通配符支持 * 和 ?；条件对所有目标同时成立才显示动作，不替用户缩减选区。

在“场景与整理”添加菜单方案，勾选动作和可选自动匹配目录。工具栏不受方案筛选，原生 Shell 项目保持现有规则。自动模式对所有目标选取最深匹配目录；无匹配使用手动方案，同目录重复方案按列表先后取第一个。空方案可刻意不勾选任何增强动作，默认方案提供全部已启用增强动作。程序可用性、动作自身规则、扩展名和多选方式仍继续生效。

托盘右键的“菜单方案”可开启自动选择或直接切换。手动选择会关闭自动模式。设置中可以用最近选区测试规则与方案，测试不运行动作；保存仍经过现有配置冲突检测与原子替换。

## 自定义分组

内置动作和自定义动作均可填写分组名，留空表示不分组。支持一层子菜单；工具栏不分组。同一分组在一级区和“更多项目”区分别收集，位置取该区域第一个成员的位置，成员保留原顺序；要集中到同一个入口，请将成员的“直接显示”设置保持一致。没有可见成员时不产生空分组，搜索结果带分组名称。

分组和规则包含在动作交换格式 2 中；旧格式 1 仍可读取，1.10.0 不能读取新的格式 2。方案和收藏目录不属于动作交换文件。

## 批量重命名

在增强菜单“更多项目”中选择“批量重命名…”，也可在内置动作页启用直接显示。支持前后缀、区分大小写的查找替换、主文件名大小写、编号起始值和位数；编号按捕获的选区顺序附在扩展名前。文件夹按完整名称处理，文件扩展名保留。

每次 1–1000 项，先生成预览；名称重复、保留设备名、非法字符、目标已存在、父子同时选中和符号链接／目录联接会阻止执行。预览在 worker 上读取指纹，可以取消；预览后编辑规则会使执行按钮失效。执行前重新校验名称占用和源指纹，原文件内容或目标变化时要求重新预览。

先把变化项目移到同目录的唯一临时名称，再改为最终名称，因此支持名称互换、循环和仅大小写变化。移动禁止覆盖。失败或取消会尝试恢复原名称；如果外部程序占用或改动导致恢复失败，会报告所有保留位置。该恢复不是跨进程崩溃或掉电的原子承诺，窗口不持久化日志。

执行后可在本窗口撤销一次，关闭窗口后撤销记录消失。撤销前核对文件 SHA256、大小和时间戳，文件夹只核对自身时间戳，不递归比较内部内容；原名称被占用或目标变化时拒绝自动撤销。全局只允许一个重命名窗口处理一组选区；正常退出会取消并等待当前处理收尾，遇到恢复错误时保留窗口供检查。

## 收藏目录复制／移动

在“场景与整理”添加名称、绝对目录及可选“当天日期子目录”，保存后增强菜单提供“复制到”和“移动到”。最多 50 个收藏目录，按列表顺序呈现。方案中的两个收藏动作控制这两个入口是否显示。

菜单生成时不检查收藏目录是否在线，避免网络访问阻塞菜单。实际执行在独立 Shell 宿主上检查基础目录，基础目录不存在时报告需要重新选择；仅明确开启的日期子目录可以自动创建。禁止传输到源目录自身、内部目录、项目原所在目录，以及父子项目同时选中。

传输使用 Windows IFileOperation，保留系统冲突选择、进度、权限提示和取消，不改变剪贴板。操作请求设置系统撤销记录标志，实际能否撤销取决于 Windows 和目标；本轮不声称完成 Explorer 撤销实测。取消、跳过或失败可能留下已完成部分，IPC 断开不强制终止传输宿主。最多 10000 个选中项目，目录内部数量由 Windows 处理。

## 兼容与验证

AppConfig schema 从 2 升至 3，v1/v2 逐级内存迁移，默认规则不增加限制。保存前不改原配置，保存保留 .bak；旧版本不支持 schema 3。与 batch-rename 或 favorite: 命名空间冲突的旧自定义 ID 稳定重分配，保留动作内容。没有新增 NuGet 依赖。

开发回归包含规则目录边界、名称与数量、自动方案优先级、克隆隔离、升级迁移、分组搜索和原生命令绑定、动作交换往返；文件夹和文件的实际改名／撤销、目标冲突、过期预览、内容变化、取消及阶段失败恢复；真实独立 Shell 宿主复制／移动、WPF 设置草稿撤销和小工作区按钮可达。当前执行范围见 [QA](../../../QA.md)，正式证据随 GitHub Release 发布，历史候选见 artifacts/candidates 下对应 candidate-manifest.json。
