# BetterCM 2.0.0 验证入口

当前版本为 **2.0.0**（2026-10-25）。本轮功能包括场景规则与菜单方案、自定义分组、批量重命名及收藏目录复制／移动。开发候选中 QA/Release 各 410 项 xUnit、73 项脚本、321 项 UI/Shell、QA 独立身份 13 项安装检查通过。正式发布从主仓库干净提交重新构建，完整结果、程序 Build 和哈希以发行附件证据为准。

## 本轮验证

- 规则检查目标类型、所有项目名称、数量、规范目录边界与 UNC 路径；方案检查最深匹配、全选区共同目录、手动回退与动作白名单。
- 配置覆盖 schema 2 → 3 迁移、新保留 ID 冲突迁移、深拷贝隔离、未知方案和无效嵌套值。动作交换格式 2 保留规则与分组，继续读取格式 1。
- 分组覆盖一级区、“更多”区、带分组搜索、原生绑定保留分组，以及真实侧边菜单展开。
- 文件系统回归执行真实文件／文件夹重命名、名称交换、仅大小写变化、中文和花括号、扩展名保留、目标占用、预览过期、内容变更拒绝撤销、原名占用拒绝撤销、启动前取消，以及第二项阶段失败后恢复第一项。
- WPF 检查真实预览、执行及撤销，设置草稿和已保存配置隔离、还原设置及小工作区操作按钮可达。
- 通过真实独立 Shell 宿主执行 Windows 文件复制到日期目录和移动，逐项确认源和目标内容；不是执行替身。

开发阶段原始报告与窗口截图位于 `artifacts/iteration-2.0.0/`。本地候选在独立源码快照中完成完整 verify、安装器编译和 QA 独立身份安装检查，生成 `artifacts/candidates/2.0.0-*/candidate-manifest.json`；候选记录独立快照身份。正式发行另从主仓库干净提交执行同一验证和安装检查，`artifacts/releases/2.0.0/` 包含 Setup、便携包、源码／载荷清单及报告。公开的 Verification.zip 移除本机路径和机器标识并重算公开副本哈希，保留结果、版本和构建身份。

```powershell
dotnet test .\Tests\BetterCM.Tests.csproj -c QA
.\Build-Candidate.ps1 -InstallerSmoke
# 主仓库干净提交的正式打包入口：
.\verify.ps1
.\Build-Installer.ps1 -ReuseVerifiedPublish
```

本版新增 48 项单元回归和 12 项 UI/Shell 检查，完整范围为 QA/Release 各 410 项 xUnit、73 项脚本回归、321 项 UI/Shell；以实际报告核对，不以数量替代断言及身份一致性。安装目录复测发现并修正原 Shell 复制检查过早读取的问题：等待完整内容可读及移动源消失，保留五秒上限和真实内容断言，另有写入锁回归。正常退出会取消并等待重命名收尾；恢复遇到错误则保留窗口供检查。

本轮不包括真实代码签名、正式身份 Setup 的实际安装、干净 VM、混合 DPI、屏幕阅读器和 Explorer 文件操作撤销实测。批量重命名撤销只在当前窗口存活，不提供掉电／进程崩溃恢复；文件夹内部内容不递归做撤销快照。QA 独立身份安装通过不能替代上述验证。
