# BetterCM 2.1.0 验证入口

当前版本为 **2.1.0**（2026-10-25）。本轮实现重命名／路径／最新选区修复、网络准备取消，以及完整工作区备份、重命名预设与排序、自定义动作运行时参数。正式发布从主仓库干净提交执行完整验证，程序 Build、标签、源码和报告对应同一提交。

## 验证范围

- 文件操作：预览不读取文件内容、执行单次内容校验与进度、文件标识替换检测、防写共享句柄、名称交换／大小写、执行中取消恢复、撤销提交前取消、Unicode 文本元素移除、自然／修改时间排序。
- 路径与上下文：普通／扩展盘符和 UNC 等价匹配，设备／ADS／歧义路径拒绝；最近选区实时读取且保留设置草稿；无效名称显示拟生成值。
- 工作区：全部字段往返、严格格式与版本、UTF-8／大小限制、旧文件保护、选择性合并、整体恢复无效草稿、跳过／替换／保留两份、方案引用及活动方案映射、路径边界、未知引用保留和配置冲突保护。
- 运行参数：必填、整数范围、下拉约束、可选空值、未知／重复／错误占位符、克隆隔离、单次展开、旧 input 字面模板迁移和动作交换格式 1／2 兼容；真实受控进程接收值与表单预览逐项一致。
- WPF 与 Shell：备份差异及草稿还原、预设名称显示、表单越界禁用、真实传输准备后取消不创建日期目录、准备等待取消阻止提交；原有复制／移动／安装检查继续执行。

本轮新增 **40 项单元回归、10 项 UI/Shell 检查**，完整范围为 QA 与 Release 配置各 **450 项 xUnit**、**73 项脚本回归**、发布及安装目录内各 **331 项 UI/Shell**，以及 **13 项 QA 独立身份安装／启动／退出／卸载检查**。实际通过结果和构建身份以本次发行附件为准，数量不能代替断言和身份核对。

开发报告和窗口截图位于 `artifacts/iteration-2.1.0/`；正式载荷、回执和报告位于 `artifacts/releases/2.1.0/`。公开 Verification.zip 移除本机路径、运行用户和机器标识，重算公开副本哈希，保留测试结果、版本和构建提交；源码包与便携包逐文件对照验证清单。

```powershell
dotnet test .\Tests\BetterCM.Tests.csproj -c QA
.\verify.ps1
.\Build-Installer.ps1 -ReuseVerifiedPublish
# 独立快照候选，不自动提交主工作区：
.\Build-Candidate.ps1 -InstallerSmoke
```

正式验证包含 Release／Debug／QA 零警告构建、锁文件恢复、依赖漏洞审计、格式／风格门禁、正式程序 QA 隔离及安装检查。远端 Verify／CodeQL 状态以本次提交的 GitHub Actions 为准；无交互桌面的 runner 不替代本地桌面检查。

本版未签名；正式身份 Setup 的实际安装、干净 VM、混合 DPI、屏幕阅读器及 Explorer 文件操作撤销实测尚未执行。重命名仅在当前窗口持有一次撤销记录，目录不递归快照，不提供跨崩溃／掉电恢复；原生传输失败或取消可能保留已完成部分。
