# BetterCM 2.1.0 — 2026-10-25

本轮按 2.0.0 复查建议实现四项修复、网络准备取消，以及完整备份、重命名预设与排序、运行时参数。正式附件从主仓库干净提交验证和构建，标签、程序 Build 与发行清单使用同一提交。

## 修复与重命名校验

- 菜单方案的最近选区测试在点击时读取最新上下文，显示名称、数量和捕获时间，不重载或丢弃当前设置草稿。
- 规则、收藏目录及备份映射统一比较盘符、UNC 和对应扩展前缀；拒绝设备路径、备用数据流及尾随句点／空格组件。文件系统和 Shell 接口支持范围仍由实际 Windows API 决定，失败会报告。
- 无效名称预览保留拟生成名称，例如 ?report.txt，错误原因另列，执行保持禁用。
- 预览只读取卷号、文件索引、类型、大小和时间戳，不读取全文；不保存预览时的文件内容快照。执行前复核元数据，每个变化文件读取一遍内容供撤销比较，并保留不共享写的读句柄直到操作或恢复结束。每步改名前后复核文件身份，处理 NTFS 名称隧道的创建时间变化。实际测试覆盖同时间／长度替换、并发写入阻止、第一项完成后取消并恢复全部原名。
- 内容校验、改名和撤销显示进度并检查取消；撤销提交前再次检查取消。目录只核对自身身份与元数据，不递归快照内部内容。跨崩溃／掉电恢复未实现，恢复冲突仍保留位置，不覆盖用户文件。

## 重命名预设与排序

在“批量重命名…”选择内置清理空格或自然排序编号预设，也可填写名称保存当前规则。最多 100 个用户预设，相同名称更新规则，用户预设可移除。保存立即进入已保存配置，设置页其他未保存编辑通过 rebase 保留。

支持捕获顺序、名称自然升降序、修改时间升降序；表格顺序就是编号顺序。主文件名可移除前后若干 Unicode 文本元素、清理首尾空格，再进行查找替换、大小写、前后缀和编号；文件扩展名保留。每次 1–1000 项，符号链接、目录联接及父子同时选中仍不处理。

## 完整备份与迁移

“备份与迁移”导出当前草稿，包括内置偏好、自定义动作／运行参数、规则／分组、方案、收藏目录、重命名预设、主题动效、快捷键和菜单行为。日志、撤销历史、当前运行输入值和登录自启项不包含在内。文件包含真实路径及显式默认值，分享前应检查。

格式为 BetterCM.Workspace / Version 1，最多 4 MiB、500 自定义动作、50 方案／收藏、100 重命名预设；严格 UTF-8、未知字段及未来 schema 检查，原子导出保护旧文件。

导入先列出差异，选择整体恢复或类别合并。同 ID 可以跳过、替换或保留两份；保留两份会生成新 ID，并将导入方案引用、手动方案 ID 重连到对应导入项目。内置偏好仅在选择替换时覆盖，系统固定／隐藏集合按策略处理；未知动作引用保留并计数。可把指定旧根目录映射到本机新根目录，保持目录边界，仅处理选定类别中的已知路径字段。

导入只加载设置草稿，可以撤销，保存后生效。确认期间配置变化或已有外部冲突会阻止覆盖；整体恢复可替换无效的未保存草稿，但不绕过配置文件损坏／格式过新的原有保存保护。旧配置异常时应先用现有恢复入口或修复配置，再保存导入结果。

## 运行时参数

自定义动作编辑器展开“执行前填写的参数”，定义小写英文开头的标识、显示名称、文本／整数／下拉类型、默认值、必填及范围或选项。最多 20 个参数，每项输入最多 1024 字符；模板中使用 {input:标识}。

运行前显示表单和实际启动计划，越界或缺失必填内容时不能确认。参数模板先拆成独立参数，再对原模板单次展开路径与运行输入；输入中的空格、引号、花括号和占位符文本保持原义，不递归替换。自定义解释器仍遵循目标程序自身语义。表单确认值被复制到执行计划，不写入配置；显式默认值随备份导出。

schema 3 → 4 增加空参数和预设列表；旧模板已有的 input 字面文本，以及旧动作交换格式 1／2 中的同类内容兼容保留。定义运行参数后再按新的 input 占位符语义校验。动作交换格式 3 包含参数定义，旧格式可继续读取。

## 网络准备与发布验证

收藏传输先启动独立宿主准备，十秒预算包含启动。准备仅读取并校验路径，取消不创建日期子目录、不传输文件；取消可关闭未提交操作的宿主。准备成功后由一次性会话令牌提交复制／移动，此后使用 Windows 冲突、进度、权限及取消界面，IPC 关闭不强杀已提交操作。源或目标在准备之后变化时仍由实际执行报告错误，操作失败／取消可能保留已完成部分。
