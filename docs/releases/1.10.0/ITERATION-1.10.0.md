# BetterCM 1.10.0 — 2026-10-23

本轮围绕自定义动作的配置体验迭代，不增加 AppConfig 字段，配置 schema 仍为 2。

## 启动预览

编辑窗口左侧修改动作，右侧实时显示程序、预计启动次数、管理员状态、每次启动的工作目录及独立参数。可以选择单文件、两个带空格的文件、文件夹或最近一次物理选区。示例文件不需要存在。预览不会解析或启动程序，也不探测文件系统；程序名尚未确定为绝对路径时会提示先选择程序。停用动作的预览不会改变其启用状态。

预览和真实执行共用 CustomActionPlan，按原模板单遍展开 {path}/{dir}/{name}，独立的 {paths} 展开为多个参数；文件名里出现的占位符文字不再展开。single/each/batch 分别对应单选、逐个与批量启动。目标目录取自捕获的文件/文件夹类型，预览和执行保持一致。展示最多前三次启动、每次前 40 个参数、每项前 512 字符，明确标记未展示部分；实际执行不因此截断。

## 模板

- 记事本：逐个打开文本文件。
- VS Code：批量传入文件或文件夹，选定本机 Code.exe 后使用。
- Windows Terminal：对一个目标打开所在目录，选定本机 wt.exe 后使用。
- PowerShell：逐个运行 .ps1，不设置 ExecutionPolicy、不默认申请管理员权限。

使用模板只填充编辑草稿。浏览选择程序及保存时的绝对路径解析继续沿用原流程；取消编辑不会修改原动作。

## 导入导出

自定义动作页新增导入、导出按钮，经典模式也可使用，不自动切换到增强模式。导出的内容为当前列表（包括未保存编辑），包含真实程序路径与参数，用于备份或迁移。

文档格式为 `{"Format":"BetterCM.CustomActions","Version":1,"Actions":[...]}`，最多 1 MiB UTF-8 / 500 项。拒绝不支持的版本、未知字段、重复或保留 ID、空值以及无效的参数模式。导入只处理动作，不覆盖主题、快捷键或其他配置，不解析程序或执行动作。

确认窗口展示导入的名称、程序、参数、多选方式、管理员、目标工作目录和启用状态，提供跳过、替换与保留两份。先按 ID 识别重复，再按名称、程序、参数、模式、提升权限、工作目录策略及扩展名集合识别相同配置；启用和一级显示偏好不用于判断相同启动配置。替换保留原位置与 ID，保留两份时为冲突 ID 分配新值。确认后加入待保存列表，仍需点击保存，也可撤销。

导出写同目录临时文件并刷新，成功后才替换目标；校验失败或写入失败不覆盖旧文件。

## 验证

新增 37 项 xUnit 和 11 项 UI/Shell 检查，开发阶段 362 项 xUnit、309 项 UI/Shell 已通过。包括带空格/花括号路径、三种模式、导入限额与失败保护、重复策略、草稿撤销、较低工作区布局，以及受控 QA 程序实际收到的参数和工作目录与预览计划一致。截图及报告位于 `artifacts/iteration-1.10.0/`。

正式发布应从主仓库干净提交完整运行 verify、Build-Installer 和 QA 独立身份安装检查，标签、程序 Build 与回执使用同一提交。实际结果随 GitHub Release 的 Verification.zip 发布；远端 Verify 和 CodeQL 以对应提交 Actions 记录为准。

代码签名、正式身份 Setup 的实际安装、干净 VM、混合 DPI 和读屏实测未包含在本轮自动化范围内。QA 独立安装身份通过不能替代上述验证。
