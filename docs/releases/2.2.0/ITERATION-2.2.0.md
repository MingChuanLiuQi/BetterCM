# BetterCM 2.2.0 — 2026-10-25

## 重命名历史

默认记录最近 20 次已完成的批量重命名。关闭原窗口或重启程序后，进入设置“操作历史”，选中任务，打开“查看与撤销”，检查原名称／新名称，点击“校验并撤销”。完整路径在悬停提示中。普通重命名窗口与历史详情互斥，避免同时撤销或修改同一事务。

撤销重新核对卷号和文件索引、类型、大小、时间、文件 SHA256，并检查原名称未被其他文件占用；不覆盖已有文件。目录只核对自身身份与元数据，不递归记录其内容。文件已变化时拒绝撤销，不以文件名相同推定为同一文件。

记录在数据目录 rename-history.json，仅保存路径、身份、SHA256 和完成时间，最多 8 MiB，不含文件内容，也不加入完整配置备份或诊断导出。可关闭以后任务的历史保留、移除单条记录或清理已撤销记录；关闭开关不会删除已有记录，移除记录不会操作文件。开关立即保存，其他设置草稿继续保留。

历史保存失败不会撤销已成功的改名，原窗口仍可撤销。撤销前先持久保存“撤销中”；如果意图无法保存，则不移动文件。文件恢复成功但最终状态保存失败时明确提示文件已撤销；历史可能显示中断，需要人工检查。中断状态不能自动重放。这一版只提供已完成任务的持久撤销，不提供执行中断、崩溃或掉电的自动恢复。

## 勾选预览

生成预览后可取消勾选单个项目、全选或排除当前预览中的全部冲突项。改动选择后，执行按钮禁用；必须重新预览，对所选原项目重新排序、编号和检查占名。排除项留在表格中，仍可重新勾选。若排除项占用了其他所选项目的目标名，重新预览会如实报冲突，不假设它也会移动。

只有当前有效计划中的勾选项参与执行。处理及已完成事务存续时不能修改勾选；撤销后可再次预览。空选区或仍有冲突时不能执行，已有文件不被覆盖。预览表禁止列排序，避免显示顺序与编号顺序不一致。

## 修复与配置

- 完整备份及动作导出拒绝覆盖正在使用的 config.json、其 .bak 或历史文件。规范化路径并比较已有文件身份，识别指向同一文件的其他路径；检查在后台执行。保护用于避免误覆盖，不承诺消除全部并发文件系统竞态。
- 保存预设后选中刚保存的项，同名更新保持稳定 ID；应用用户预设时填入名称，方便修改后保存。内置预设需要填写名称另存。
- 方案与收藏目录都可上移／下移，保存真实集合顺序。禁用仅改变显示的列排序；同深度目录匹配时靠前方案优先，手动活动方案保持不变。
- 配置 schema 5：schema 4 → 5 开启 KeepRenameHistory，其他配置继续逐级迁移。完整备份只携带开关；工作区文档 Version 1、动作交换 Version 3 不变，无新增 NuGet 依赖。
