## 健壮性与超时压力

`artifacts/qa/published-stress-0.4.0.json` **58/58** 通过。测试使用专用假 Shell 宿主，在 STA 上执行真实 `Thread.Sleep(40s)`，不执行用户文件动作。

| 检查 | 实测结果 |
| --- | --- |
| 40 秒 invoke 期间第二次 open | 33.79 ms，使用预热独立连接 |
| 50 次连续 open 的请求关联 | 50/50 正确，p50 0.22 ms，最大 0.56 ms |
| invoke 30 秒等待超时 | 返回通信失败，宿主仍存活 |
| bridge Dispose | 正在执行的宿主仍存活 |
| 40 秒命令完成 | IPC 已关闭，宿主完成后自行退出 |
| 卡住上下文捕获 | 1805.64 ms 返回降级结果，日志记录 context-timeout |
| 超时后下一次捕获 | 249.20 ms，新捕获进程正常返回 |
| 主动 CancellationToken 取消 | 被取消捕获废弃，下一次正常返回 |

这些数字只验证通信与隔离设计，假宿主不代表全部真实 Shell 扩展的速度，也不包含完整菜单捕获、UI 帧时间及冷启动时延。该压力报告是在最终 HoverExpansion 修复前的发布负载上运行；本次悬停修改没有改变所测 Shell/上下文实现，最终负载的组件与安装回归另见上节。
